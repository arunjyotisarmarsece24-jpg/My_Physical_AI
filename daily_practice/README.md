# Daily Practice Labs

This directory contains individual daily coding labs. Each day tackles a focused, mathematically rigorous problem in Physical AI.

## Daily Workflow for Practice
1. **Pick the task** from [`DAILY_ROADMAP.md`](../DAILY_ROADMAP.md).
2. **Implement & test** the code locally in its respective `day_XX_*` folder.
3. **Run both visual and headless checks**:
   ```bash
   python daily_practice/day_XX_.../script.py
   ```
4. **Commit & Push to GitHub**:
   ```bash
   git add .
   git commit -m "feat(day-XX): complete <topic-name>"
   git push origin main
   ```
This builds an unshakeable commit history demonstrating real physical AI and robotics expertise.
